# Evaluation on real data

Generated by `dealroom real eval`. Sources are pinned in `data/real/manifest.json` and not committed.

## FinanceBench (SEC filings, human-written questions)

150 questions on 84 10-K/10-Q/8-K filings ([Patronus AI](https://github.com/patronus-ai/financebench), CC BY-NC 4.0). Each question is searched within its own filing. A hit means a retrieved chunk is on a page the annotators marked as evidence. Filings are extracted as layout-sorted text without cell-level table detection.

| Method | Page hit@1 | Page hit@5 | Page hit@10 |
| --- | --- | --- | --- |
| BM25 | 22.0% | 39.3% | 53.3% |
| Dense (local LSA) | 18.7% | 36.7% | 44.0% |
| Hybrid (RRF) | 22.7% | 40.7% | 49.3% |
| Hybrid + rerank | 18.0% | 42.7% | 52.0% |

Page hit@5 (hybrid + rerank) by question type: domain-relevant 26.0%, metrics-generated 40.0%, novel-generated 62.0%.

Answers with model `stub`: abstained on 133 of 150 questions. Figure accuracy (questions whose gold answer is a single figure): domain-relevant 0.0% of 1, metrics-generated 0.0% of 50, novel-generated 0.0% of 1.

The offline stub only quotes passages, so it cannot answer questions that need a calculation, and its lexical abstention rule rejects most of FinanceBench's long questions. Answer quality on real filings needs a real model and has not been measured.

## CUAD (commercial contracts, lawyer labels)

Does a contract contain a change-of-control provision (termination, consent or notice when a party changes control)? Scored on CUAD's test split (102 contracts, [The Atticus Project](https://github.com/TheAtticusProject/cuad), CC BY 4.0). Version 1 is the pattern set written for the synthetic contracts. Version 2 was developed on CUAD's training split (408 contracts) and scored on the test split once.

| Detector | Precision | Recall | F1 |
| --- | --- | --- | --- |
| v1, provision present | 63.2% | 46.2% | 0.533 |
| v2, provision present | 73.7% | 53.8% | 0.622 |
| v1, termination right only | 100.0% | 11.5% | 0.207 |
| v2, termination right only | 100.0% | 11.5% | 0.207 |

26 of 102 test contracts carry a provision. The challenger raises an argument only for a termination right, which real contracts express in many more ways than its pattern covers: it finds few of them, but every one it flags is real.
